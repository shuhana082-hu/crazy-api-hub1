# Name Check API – বিক্রির ওয়েবসাইট

ইউজার প্যানেল + অ্যাডমিন প্যানেল + API gateway (প্যাকেজ, মেয়াদ, রিকোয়েস্ট লিমিট)।

## ফাইল (সব একই ফোল্ডারে, কোনো সাবফোল্ডার নেই)
`server.js`, `index.html`, `style.css`, `app.js`, `admin.js`, `package.json`

## ১. ডেটাবেজ
আলাদা ডেটাবেজ লাগবে না। `DATABASE_URL` না দিলে সাইটের ভেতরেই ডেটাবেজ চলে (`data` ফোল্ডারে)।
সাবধান: Render ফ্রি প্ল্যানে ফাইল স্থায়ী নয়, নতুন ডিপ্লয় বা রিস্টার্টে ডেটা মুছে যায়।
ডেটা স্থায়ী রাখতে চাইলে neon.tech-এর ফ্রি PostgreSQL-এর লিংক `DATABASE_URL`-এ দিন।

## ২. Render-এ ডিপ্লয়
New → Web Service → GitHub repo যুক্ত করুন → Environment-এ দিন:

| Key | Value |
|---|---|
| `DATABASE_URL` | (ঐচ্ছিক) বাইরের PostgreSQL লিংক। ফাঁকা রাখলে ভেতরের ডেটাবেজ চলবে |
| `SESSION_SECRET` | যেকোনো লম্বা র‍্যান্ডম লেখা (৩২+ অক্ষর) |
| `ADMIN_EMAIL` | আপনার অ্যাডমিন ইমেইল |
| `ADMIN_PASSWORD` | শক্ত পাসওয়ার্ড (৮+ অক্ষর) |
| `SITE_NAME` | সাইটের নাম |
| `NODE_ENV` | `production` |
| `BEHIND_CLOUDFLARE` | Cloudflare চালু করলে `true`, না হলে `false` |

প্রথমবার চালু হলে অ্যাডমিন অ্যাকাউন্ট নিজে তৈরি হবে। সাইটে গিয়ে ওই ইমেইল/পাসওয়ার্ডে Sign In করলে **Admin Panel** খুলবে।

## ৩. অ্যাডমিন প্যানেলে প্রথম সেটআপ
1. **Servers** → Add server: আপনার নেম-চেক সার্ভারের লিংক (যেমন `https://xxx.onrender.com`) আর ওই সার্ভারের `API_KEYS` এর মান।
2. **Settings** → bKash/Nagad নম্বর, সাইটের নাম, নোটিশ দিন।
3. **Packages** → প্যাকেজের দাম, রিকোয়েস্ট সংখ্যা, মেয়াদ (দিন) ঠিক করুন।

## ৪. কীভাবে কাজ করে
- ইউজার রেজিস্টার করলেই `sh-...` কী নিজে তৈরি হয়।
- ইউজার Add Money-তে টাকা পাঠিয়ে Transaction ID জমা দেয় → অ্যাডমিন **Deposits** থেকে Approve করলে ব্যালেন্স যোগ হয়।
- ইউজার **Upgrade API** থেকে প্যাকেজ কিনলে রিকোয়েস্ট ও মেয়াদ চালু হয়। আগের প্যাকেজ চালু থাকলে রিকোয়েস্ট যোগ হয় ও মেয়াদ বাড়ে।
- API: `GET https://আপনার-ডোমেইন/api/v1/name?uid=UID&key=sh-...`
- মেয়াদ শেষ বা রিকোয়েস্ট শেষ হলে API `402` দেয়, ইউজারকে সাইটে এসে নতুন প্যাকেজ কিনতে হয়।
- শুধু সফল লুকআপে রিকোয়েস্ট কাটে। Not found বা সার্ভার এরর হলে ফেরত যায়।
- সার্ভার একাধিক যোগ করলে একটা ডাউন হলে পরেরটায় নিজে চলে যায়। প্রতি ৪ মিনিটে সব সার্ভারে পিং যায় (ফ্রি Render সার্ভার ঘুমায় না)।

## ৫. Cloudflare
ডোমেইন Cloudflare-এ যোগ করে Render-এর লিংকে CNAME (Proxied) দিন, SSL mode **Full**। তারপর `BEHIND_CLOUDFLARE=true` করুন, যাতে রেট লিমিট আসল IP ধরে।

## ৬. মনে রাখবেন
- ফ্রি Render সাইটও ১৫ মিনিট অব্যবহৃত থাকলে ঘুমায়। UptimeRobot দিয়ে `/health` পিং করুন।
- ইউজারের পাসওয়ার্ড হ্যাশ করে রাখা হয়, কী শুধু ইউজার ও অ্যাডমিন দেখতে পান।
